## 📝 STAR Reflections

### 1. Reflection on Coding in Markdown

**Situation**  
As part of my PRP370 assessment for Project Presentation 3, I was required to create a digital portfolio using GitHub and code my CV using Markdown. I had never used Markdown before.

**Task**  
I needed to learn Markdown from scratch and successfully code my CV so that it would display correctly on GitHub Pages, using proper formatting such as headings, tables, lists, and links.

**Action**  
I started by watching YouTube tutorials on Markdown basics and reading documentation on GitHub Flavoured Markdown (GFM). I practised writing simple Markdown elements like headings, bullet points, and tables in Visual Studio Code before structuring my full CV. I then wrote my CV section by section, checking the preview regularly to ensure formatting was correct.

**Result**  
I successfully coded my CV in Markdown, which now displays cleanly on my GitHub Pages portfolio. I gained a new technical skill that I can use for future documentation, README files, and portfolio projects. This task also gave me confidence in learning new syntax quickly.

---

### 2. Reflection on Mock Interview Video Experience

**Situation**  
As part of my PRP370 assessment and work readiness training, I needed to complete a mock interview to prepare me for the professional world. The goal was to demonstrate that I can present myself confidently and prove that employers can trust me with their projects.

**Task**  
I applied for a **UX/UI Intern role**. I needed to answer interview questions clearly, showcase my relevant skills (Figma, wireframing, prototyping, user-centered design), and convince the interviewer that I am a capable and trustworthy candidate.

**Action**  
I prepared thoroughly by creating flashcards with common UX/UI interview questions and practicing my answers daily. I also rehearsed in front of a mirror to improve my body language, eye contact, and tone of voice. Mentally, I visualised myself succeeding in the interview and reminded myself of my past projects (like the Everything Co. design system and Talent marketplace). I then recorded my mock interview and uploaded it to Canva.

**Result**  
The experience taught me that taking time to reflect on my work helps me recognise my own potential. I realised that my skills and projects make me valuable to employers, and I am not just another candidate – I am someone who can genuinely contribute. I learned to speak about my work with more confidence and will continue practising to reduce nervous pauses in real interviews.

---

### 3. Reflection on the Use of GitHub Pages

**Situation**  
After coding my CV and preparing my mock interview video, I needed to publish my digital portfolio online so my lecturer could access it via a link for assessment.

**Task**  
I had to deploy a GitHub Pages site from my repository and ensure all content (CV, video link, reflections) was visible and working correctly.

**Action**  
I created a new repository named `liyabonangece16.github.io` on GitHub. I uploaded my `index.md` file containing my CV and reflections, along with my mock interview video link. I then went to **Settings → Pages** in the repository, selected the `main` branch as the source, and saved the changes. After waiting a few minutes for deployment, GitHub automatically generated a live URL for my site.

**Result**  
My portfolio is now live at `https://liyabonangece16.github.io/`. Seeing my work published online made me realise I had done something extraordinary – I had built and deployed my own professional portfolio from scratch. I learned that static website hosting is accessible and powerful, and this skill will be valuable for future freelance work and job applications.
